📖 Project Overview

Simon Game is a classic memory game where players have to repeat the exact sequence of colors shown by the game. After every successful round, a new color is added to the sequence, making the game progressively more challenging.

The game also keeps track of:

🎯 Current Score
🏆 Highest Score (during the session)

This project focuses on implementing the complete game logic using Vanilla JavaScript without relying on any external libraries or frameworks.

🎯 How to Play
Press any key (or the Start button if available) to begin the game.
Watch the highlighted color carefully.
Repeat the same pattern by clicking the colored boxes.
Every successful round adds one more color to the sequence.
Continue remembering and repeating the pattern.
The game ends if you click the wrong color.
Try to beat your Highest Score.
